# Portfólio Back-end — Antony Matheus

Portfólio pessoal desenvolvido para apresentar minha trajetória, habilidades, projetos e informações profissionais como desenvolvedor back-end com foco em Java.

## 📌 Sobre o projeto

Este projeto consiste em um site de portfólio responsivo, desenvolvido com tecnologias web fundamentais, com foco em uma apresentação profissional, moderna e funcional.

O site reúne informações sobre:

- Perfil profissional;
- Formação acadêmica;
- Habilidades e tecnologias;
- Projetos desenvolvidos;
- Experiências e conhecimentos;
- Formas de contato;
- Currículo para visualização e exportação em PDF.

## 🚀 Tecnologias utilizadas

- **HTML5** — estrutura e organização das páginas;
- **CSS3** — estilização, layout, responsividade e animações;
- **JavaScript** — interações, funcionalidades e comportamento dinâmico da aplicação.

## 📂 Estrutura do projeto

```text
.
├── index.html
├── style.css
├── script.js
└── README.md
```

> A versão `index_integrado.html` contém o JavaScript incorporado diretamente ao HTML, eliminando a necessidade do arquivo `script.js` para essa versão.

## ⚙️ Funcionalidades

### 🎨 Interface

- Layout responsivo para diferentes tamanhos de tela;
- Seções organizadas para apresentação profissional;
- Animações e efeitos de interação;
- Navegação entre as diferentes partes do portfólio.

### 💻 Projetos

A seção de projetos permite apresentar trabalhos desenvolvidos, suas respectivas descrições e informações relacionadas às tecnologias utilizadas.

### 📄 Currículo

O portfólio possui uma funcionalidade para visualizar e **exportar o currículo em PDF**.

A exportação utiliza uma visualização específica para impressão, configurada para o formato A4 e preparada para evitar cortes de conteúdo e páginas em branco.

### 📱 Responsividade

O layout foi desenvolvido para funcionar em:

- Computadores;
- Notebooks;
- Tablets;
- Smartphones.

## ▶️ Como executar

Como o projeto utiliza HTML, CSS e JavaScript puro, não é necessário instalar dependências ou configurar um servidor para uma execução básica.

### 1. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Entre na pasta

```bash
cd nome-do-projeto
```

### 3. Execute

Abra o arquivo `index.html` diretamente no navegador.

Também é possível utilizar uma extensão como **Live Server** no Visual Studio Code para executar o projeto durante o desenvolvimento.

## 🛠️ Desenvolvimento

Durante o desenvolvimento, o projeto foi organizado separando estrutura, estilos e comportamento:

- `index.html` → conteúdo e estrutura;
- `style.css` → aparência e responsividade;
- `script.js` → funcionalidades e interações.

Para a versão integrada, o JavaScript foi incorporado ao próprio `index.html`.
